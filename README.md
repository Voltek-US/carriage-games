# Carriage Games

Eleven two-player games played phone to phone with no internet: Chess, Texas Hold'em, Liar's Dice, Yahtzee Duel, Checkers, Othello, Gomoku, Ultimate Tic-Tac-Toe, Mancala, Nine Men's Morris and Quoridor.

Phones connect directly over a shared hotspot or Wi-Fi (WebRTC data channel, paired by scanning QR codes). After the first visit the app is cached by a service worker and works fully offline.

Chess board: [Chessground](https://github.com/lichess-org/chessground) (GPL-3.0) with cburnett pieces (CC BY-SA 3.0, Colin M.L. Burnett). Fonts: Fraunces (SIL OFL). QR: jsQR, qrcode-generator (MIT).
